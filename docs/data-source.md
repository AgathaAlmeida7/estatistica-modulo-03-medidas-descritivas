# Fonte dos Dados

## Dataset

Brazilian E-Commerce Public Dataset by Olist

## Fonte

Kaggle:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Descrição

Dataset público de e-commerce brasileiro contendo dados
anonimizados relacionados a pedidos, clientes, produtos,
vendedores, pagamentos, avaliações e logística.

## Uso dos dados

Os arquivos originais não são redistribuídos neste
repositório.

A análise utiliza os dados localmente, respeitando as
condições de uso e licença apresentadas pela fonte original.

## Observação

A licença e as condições de uso devem ser verificadas na
fonte oficial antes de qualquer redistribuição ou utilização
comercial dos dados.
