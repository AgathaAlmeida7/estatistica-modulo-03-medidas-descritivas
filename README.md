# Diagnóstico Estatístico de Vendas e Comportamento de Pedidos

Projeto de análise estatística descritiva aplicado a dados reais de e-commerce, desenvolvido como parte da formação em Estatística.

## Objetivo

Investigar o comportamento estatístico das vendas e dos pedidos, aplicando medidas de tendência central, posição, dispersão, distribuição e identificação de valores extremos.

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

Fonte:
https://www.kaggle.com/olistbr/brazilian-ecommerce

Os dados originais não são redistribuídos neste repositório.
